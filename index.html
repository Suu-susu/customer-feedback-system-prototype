Tait Hub Customer Feedback System Prototype

A self-directed UX/UI and web platform concept project by Jiashuo Su. It shows a complete feedback loop: page-level submission, automatic context capture, triage, filtering, ownership, status updates, and simple reporting.

Case study

UX/UIWeb platformCustomer feedbackTriage workflowInteractive prototype

Problem

Users of technical platforms often notice documentation gaps, confusing workflows, or product issues while completing a task. Generic support channels can lose page context, severity, and reproducible detail.

Design goal

Create a lightweight feedback system that is quick for the user, structured enough for support triage, and useful for product, UX, documentation, and engineering teams.

Primary user groups

  • Field users who need to report an issue without leaving the page.
  • Support teams who need severity, category, context, and contact information.
  • Product and UX teams who need repeated patterns, not isolated comments.
  • Engineers who need reproducible context before investigating an issue.

Prototype flow

1User opens feedback from the page where the issue happened.
2The widget captures page title, section, category, severity, and notes.
3A reference number confirms that the feedback was received.
4The triage dashboard groups issues by priority, category, owner, and status.
5Teams review details, update status, copy references, and export a summary.

Validation plan

  • Ask 3-5 users to submit sample feedback from technical content pages.
  • Measure whether users can complete a submission in under one minute.
  • Check whether support and product stakeholders can triage from the captured fields.
  • Iterate labels, categories, and confirmation copy from observed hesitation points.
